# Per-post checklist — zenith-studio Instagram content

Derived from insta/research/competitor-analysis.md. Run every course/service post through this
before it ships.

## 1. Hook (first line / first slide)
- [ ] Line 1 gives immediate context — no delayed reveal (skip rate rises if context isn't instant)
- [ ] Opens a curiosity gap ("the lean") — makes the reader want the next line
- [ ] Has a contrarian turn somewhere before the payoff (says something that cuts against what
      they expected) — not required on every post, but strongest hooks have it
- [ ] For reels specifically: the cover-frame text alone must carry the hook, since autoplay
      previews are often muted/paused

## 2. CTA
- [ ] Ends with a comment-keyword CTA ("Comment 'X' and I'll send you...") — not just "link in bio"
- [ ] Keyword is short, one word, easy to type (e.g. "TEAM", "AUDIT", "LAW")
- [ ] What they get for commenting is real and specific (a guide, a breakdown, a checklist) — not vague

## 3. Design
- [ ] Cream/off-white background + one bold accent color + thick condensed headline type
      (default template — differentiates from generic black-gradient "AI account" look)
- [ ] For a service/workflow explainer: horizontal pill-icon pipeline (problem → agents → result),
      one label per step, consistent icon style
- [ ] For a stat/case-study post: real numbers stated plainly, no design flourish competing with them
- [ ] Minimal text per slide — one idea per slide, not paragraphs

## 4. Caption structure
1. Hook line (see section 1)
2. 2-4 short lines of context/problem
3. The mechanism/what we built (bullet list reads better than prose)
4. Comment-keyword CTA, repeated at the very end

## 5. Before publishing
- [ ] Would this stop a scroll from someone who doesn't already know us?
- [ ] Does it read like an ad, or like something worth saving/sharing?
