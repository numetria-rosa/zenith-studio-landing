<Def title={"What you need before starting"}>

Basic programming fundamentals: variables, conditions, loops, functions, basic data structures (lists, dictionaries), and a rough idea of what an API call is. That's it.

<Assume>

You do NOT need prior Python, AI/ML, LLM, RAG, vector-database, or agent-framework experience. This course teaches the Python and the AI engineering skills required to progress, in that order, together.

</Assume>

## Core skills taught in this course

**Python for AI Engineering** (the language every exercise, project, and the capstone are built in), APIs, structured outputs, context/token management, retrieval-augmented generation, vector search, tool calling, agents, evaluation, reliability, AI application architecture, and 8 hands-on projects.

## Skills to develop after the core course

Advanced Python, advanced SQL, advanced backend engineering, Docker, cloud platforms, CI/CD, Kubernetes, classical ML, model fine-tuning, and large-scale infrastructure. These are genuinely useful NEXT-STAGE skills, not prerequisites for starting here, you don't need any of them to begin Module 1.

</Def>
