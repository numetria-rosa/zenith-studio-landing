## What this module assumes

No prior AI/ML background is assumed. If you've used a chat interface, you already have the raw material, this module is about what changes when the consumer of the output is a program instead of a person reading a screen.

## What's new

This course does not call a real hosted model API, network cost and reliability aren't the point of Module 1. Instead you'll work with realistic, representative raw model output as fixed text, exactly the kind of malformed and well-formed responses a real model produces, and build the validation logic a production system actually needs around it.
