## What this module assumes

Module 2 solved "how do I fit content into a budget" with chunking. It didn't solve "which chunk is actually relevant to this specific question." Retrieval is that second problem: searching across many chunks and pulling only the ones worth spending tokens on.

## What's new

Vectors and cosine similarity, the actual math retrieval systems use to rank relevance. You'll compute it by hand conceptually, then implement it.

## What's assumed

<Assume>

Modules 1-2 completed. Arrays, loops, basic arithmetic. No linear algebra background needed, everything here is built from scratch.

</Assume>

## How to work through it

1. Read each definition, then run the matching interactive.
2. Answer the practice check before revealing the answer.
3. Finish with the graded checkpoint.
