## Why you're learning this

Every module so far has treated probability and optimization as separate
subjects. This module fuses them: fitting a model to data is, very often,
choosing the model parameters that make the observed data as plausible as
possible under that model. That single idea — maximum likelihood
estimation — is the reason many common loss functions (mean squared error,
cross-entropy) exist and look the way they do.

## 8.1 — How plausible is this data, under this model?

Given a family of candidate models (here, every possible Gaussian, defined
by its mean and spread), likelihood asks: for a specific candidate model,
how probable would it have been to see exactly the data you actually
collected?

<Callout tone="info" label="Definition">
**Likelihood** is the probability of the observed data, treated as a
function of the model's parameters (not of the data, which is fixed).
**Maximum likelihood estimation (MLE)** picks the parameter values that
make that probability as large as possible.
</Callout>

## 8.4 — Where this shows up in real machine learning

- **Mean squared error**, one of the most common loss functions in all of
  ML, is exactly what you get from maximizing Gaussian likelihood — this
  module's math, not a coincidence.
- **Logistic regression and classification losses** (cross-entropy) come
  from the same idea, applied to a Bernoulli probability model instead of
  a Gaussian one — the general pattern is identical, only the assumed
  distribution changes.
- **Bayesian methods** extend this idea by combining the likelihood with a
  prior belief about the parameters — a natural next step once likelihood
  itself is solid.

## 8.5 — A failure mode this prevents

<Callout tone="warning" label="Common mistake: assuming a loss function is arbitrary">
Loss functions can look like arbitrary engineering choices if you haven't
seen where they come from. Mean squared error isn't an arbitrary
"penalize big errors more" heuristic — it falls directly out of assuming
your data has Gaussian noise and maximizing likelihood under that
assumption. Knowing this lets you reason about when MSE is actually the
right choice (when Gaussian noise is a reasonable assumption) and when a
different loss (matching a different noise/error model) would be more
honest.
</Callout>
