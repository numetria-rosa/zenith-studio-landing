## Turn PCA into an actual decision

Knowing the PCA formulas isn't the same as being able to use them to make
a real call: "should we reduce this to fewer dimensions, and how do we
justify that?" This project reuses Module 3's lab, but this time the task
is to gather evidence and make (and defend) that decision yourself.
