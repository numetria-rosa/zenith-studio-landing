## 11.1 — Relevance, computed the same way as similarity

Attention starts by asking, for a specific word (the "query"), how
relevant every other word (each a "key") is. That relevance score is
computed exactly the way you'd expect after Module 1: a dot product.
Words whose vectors point in similar directions score higher.

<Callout tone="info" label="Definition">
**Attention** computes, for a query vector, a weighted combination of
value vectors — where the weights come from how well the query's direction
aligns (via dot product) with each corresponding key vector, normalized
into proper probabilities via softmax.
</Callout>

## 11.4 — Where this shows up in real machine learning

- **Self-attention in transformers** is exactly this computation, applied
  to every word attending to every other word in a sentence
  simultaneously, with learned (not hand-placed) query/key/value vectors.
- **Multi-head attention** runs several of these attention computations in
  parallel, each potentially learning to focus on a different kind of
  relationship between words.
- **Retrieval systems** (like the semantic search from Module 1) and
  attention are close mathematical cousins — both fundamentally rank
  relevance using dot products, just applied at different stages of a
  system.
