## Why this exists

Nothing kills confidence faster than notation that looks like a foreign
alphabet. This lesson is entirely about reading symbols, not solving
anything — the goal is that $\sum$, subscripts, and $f'(x)$ stop looking
intimidating before Module 1 uses any of them for real.

## Summation notation

<Callout tone="info" label="Reading Σ">
$\sum_{i=1}^{3} i$ means: add up the expression $i$ for every value of $i$
from 1 to 3. That's $1 + 2 + 3 = 6$. The letter above and below $\sum$ just
set the start and end of the range you're summing over.
</Callout>

You'll see this constantly from Module 1 onward — a dot product is a sum,
entropy is a sum, likelihood is a sum.

## Subscripts and superscripts

A **subscript** (a small number written below and after a letter, like
$x_1$) is a label — "which one." $x_1, x_2, x_3$ are the 1st, 2nd, and 3rd
entries of something called $x$. A **superscript** (written above, like
$x^2$) is an exponent — "raised to what power." These look similar and
mean completely different things — mixing them up is one of the most
common notation mistakes.

## Vectors and matrices

A vector written $\mathbf{v} = (v_1, v_2)$ is a list of components, each
labeled by a subscript — not a product, not separate unrelated variables,
just an ordered list belonging to one object called $v$. A matrix extends
this to a full grid, indexed by both a row and a column subscript.

## Function and derivative notation

$f(x)$ means "the rule $f$, applied to input $x$." $f'(x)$ (read "f prime
of x") is standard notation for the derivative of $f$ — its rate of
change — which Module 4 will define properly. It is not related to prime
numbers, and it is not the same as $f^{-1}(x)$, which denotes a function's
inverse.
