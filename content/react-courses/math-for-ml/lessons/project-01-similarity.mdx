## Build and understand a real similarity search engine

Every semantic search engine, every "you might also like" recommendation,
and a good chunk of what makes retrieval-augmented language models work
comes down to one operation you already know: rank a set of vectors by
cosine similarity to a query vector. This project puts that operation to
work on a small, real "document" collection, and asks you to actually
interpret what it produces, not just watch numbers change.
