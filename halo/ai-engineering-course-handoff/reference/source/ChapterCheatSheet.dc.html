Prompt pattern
SYSTEM = """You extract support tickets.
Reply with JSON only, matching this schema:
{schema}
Use null for anything the message doesn't say."""
Repair prompt
REPAIR = """Your previous reply failed validation:
{error}
Return the corrected JSON only."""
Validate at the boundary
try:
t = Ticket.model_validate_json(text)
except ValidationError as err:
t = repair(text, err) # once
Error → action
JSONDecodeErrorStrip fences and surrounding prose, then repair once
ValidationErrorRepair once, sending the exact error message
Still invalidRaise, log the raw output, route to a human queue
Empty or refusalDon’t repair. Return your fallback path
Valid but wrongBusiness-rule check: look it up before you act
Rules of thumb
Enums over free text for anything you branch on
null over an invented value
One repair, never an open loop
Log the raw output on every failure
Keep the schema small and flat
Constrained decoding fixes shape, not truth
