Extra Practice

Cross-module challenges

Bonus scenarios that combine skills from several modules at once, closer to a real messy week on the job than any single module's exercises. These ship alongside Modules 2–9 as they're built out.

In production

"The Conflicting Reports"

Two departments hand you spreadsheets that both claim to show "total monthly revenue," and the numbers don't match. Find out why, using cleaning (Module 4), statistics (Module 5), and SQL (Module 6) together, and write the memo that resolves it.

  • Combines: data cleaning, descriptive statistics, SQL
  • Format: evidence-based investigation, not a single graded exercise
In production

"The Dashboard Nobody Trusts"

An existing dashboard's numbers don't match what people see in the underlying system. Diagnose the gap and rebuild the dashboard so it's trustworthy again, combining SQL, visualization judgment, and executive communication.

  • Combines: SQL, chart/dashboard design, communication
  • Format: evidence-based investigation, not a single graded exercise
