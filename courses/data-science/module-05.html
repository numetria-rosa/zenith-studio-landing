Exploratory Data Analysis & Statistics

Descriptive statistics, distributions, correlation versus causation, and enough hypothesis-testing intuition to know when a difference is real versus noise. Includes a lesson built on Anscombe's quartet: four datasets, identical summary statistics, completely different shapes.

By the end of this module you'll be able to
  • Compute and correctly interpret mean, median, std, and percentiles
  • Tell correlation from causation, with a real example every time
  • Know when a difference between two groups is signal versus noise
  • Explain why a summary statistic alone can lie about the shape of data
