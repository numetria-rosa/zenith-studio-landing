Automation Practice Library

Real CPython running in a Web Worker (Pyodide), the same sandbox the Python Practice Library uses, applied to the specific building blocks of scripted, repeatable analyst work: parsing raw text, batching records, cleaning filenames, merging totals from separate sources, and handling bad rows without crashing the whole run.

Honest scope note: this is genuine code execution, not a simulation, every task pairs fixed test cases with one freshly randomized input compared against a hidden reference implementation, so a hardcoded return value can't pass. All 3 stages are complete, 30 tasks: Fundamentals, Report Automation (CSV generation/parsing, ranked reports, period comparison, threshold alerting, templating, idempotent aggregation), and Real-World Workflows (missing-column detection, ID-based deduplication, run-to-run diffing, bounded retries, config-driven rules, reconciliation tolerance, workflow-log summarizing, column-name normalization), ending in an independent year-end consolidation task.
