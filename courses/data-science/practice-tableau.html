Tableau Practice Library

Decision-based practice for the reasoning behind a Tableau view: which field is a Dimension vs a Measure, which shelf it belongs on, discrete vs continuous, and which chart shape a given combination of fields actually calls for.

Honest scope note, please read: this is a practice simulation, not real Tableau. Nothing here renders inside an actual Tableau workbook, and no click is graded by executing real Tableau software, this page can't run in a browser the way the Excel formula engine or the Python/SQL sandboxes do. What it genuinely checks is the reasoning: given a real field from a real dataset, do you know whether it's a Dimension or a Measure, which shelf it belongs on, and why. Every scenario is re-randomized on every attempt (a different field, a different business ask) specifically so a memorized click sequence can't pass, only the underlying rule can. Treat this as a rehearsal for the concepts, not a substitute for opening Tableau Public or Tableau Desktop and building a real workbook.
Progress: Stage 1 (Fundamentals: Dimensions vs Measures, shelves, discrete vs continuous, chart choice) and Stage 2 (Visual Analytics: quick table calculations, Compute Using, reference lines, sorting, trend lines, Top N filtering) are complete, 20 tasks.
