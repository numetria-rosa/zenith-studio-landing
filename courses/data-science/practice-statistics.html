Statistics Practice Library

Real descriptive statistics, probability, hypothesis testing, correlation/regression, and business statistical judgment, computed by real CPython (Pyodide, the same sandbox the Python library uses) against real, genuinely messy datasets, not scipy, not a formula lookup, not a fixed answer key.

Honest scope note: every task is graded by running your function AND a freshly-computed reference calculation on the same real data, twice, once on the full dataset and once on a different slice, so a hardcoded number cannot pass. No scipy is used anywhere, every p-value and confidence interval is computed from the standard normal CDF via Python's built-in math.erf, and every regression is fit with the closed-form least-squares formula, both worth knowing how to derive by hand, not just call a library for.
