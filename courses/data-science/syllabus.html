Course description

Most intro data courses hand you a dataset that's already clean and ask you to make a chart. That is not what the job is. The job is a spreadsheet with three date formats in one column, a "total" that doesn't match finance's total, and a stakeholder who wants to know why, by Friday. This course teaches the judgment underneath the tooling: how to tell whether a summary statistic is lying to you, how to clean data without quietly deleting the signal along with the noise, how to pick the chart that doesn't mislead, and how to turn a finding into a recommendation someone actually acts on.

You will finish with a portfolio of real, messy-data analysis work, not a folder of tutorial notebooks that all look the same.

Why real mess, not clean sample data: a tutorial dataset teaches you the syntax. It does not teach you what to do when a column of "numbers" is actually text, when a date parses wrong for half the rows, or when two "duplicate" records are actually different customers with the same name. Every dataset in this course has at least one of those problems on purpose, because that is the actual skill a hiring manager is checking for.

Learning outcomes

Real data cleaning

Diagnose and fix the problems that actually show up in the wild: missing values, duplicates, inconsistent categories, numbers stored as text, mixed currencies and units.

Statistics you can defend

Compute and explain descriptive statistics, tell correlation from causation, and know when a difference is signal versus noise, not just run a function and report the number.

Charts that don't mislead

Pick the right chart for the question, spot a genuinely misleading chart (truncated axes, dual-axis tricks), and build a one-page visual a non-technical reader actually understands.

A recommendation, not just a report

Turn a finding into a dashboard and a written "here's what to do" a stakeholder can act on in the same meeting.

Practice Libraries

The 9 modules teach each concept once, deliberately. Real fluency needs repetition with variation, so alongside the modules there are 8 separate practice libraries, 275 tasks total, each checked for real (a hand-built formula engine, a real SQLite database via sql.js, or real Python in a Pyodide sandbox, not a fixed-answer key), with anti-cheat built in: a re-randomized input on every check, so a memorized or hardcoded answer can't pass. See the Dashboard's skill map for real-time mastery across all of them.

SQL, Excel, Python, 145 tasks

Genuine execution, mutation-tested. SQL runs against a real SQLite database, Excel against a hand-built formula engine, Python inside a real CPython sandbox.

Tableau, Power BI, 80 tasks

Honest decision-based simulations, clearly labeled as such, since neither tool can run in a browser. Tests the reasoning (Dimension vs. Measure, shelf choice, DAX patterns), not clicking through a real desktop app.

Automation, 30 tasks

Real Python execution, parsing, batching, report generation, and fault-tolerant, idempotent pipeline design, the specific skills that separate a working script from one safe to leave running unattended.

Integrated Cross-Tool Challenges, 20 tasks

The same business question, solved with a different tool each time, and the judgment to recognize when the underlying technique is identical and when it genuinely isn't.
