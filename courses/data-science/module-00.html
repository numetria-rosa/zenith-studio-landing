What is data analysis, actually?

Data analysis is the discipline of turning raw, usually messy, records into an answer a business can act on. Not building a machine-learning model. Not writing production software. Taking data that already exists, cleaning it, finding the real pattern in it, and explaining, in plain language, what it means and what to do about it.

Definition: Data Analyst

Someone who takes existing data (spreadsheets, databases, exports from other systems), cleans it, analyzes it with statistics and visualization, and turns it into a recommendation a non-technical stakeholder can act on, everything this course's 9 modules cover, in order.

Concrete example: a retail company notices revenue is flat this quarter. A data analyst pulls the order data, cleans it, finds that the drop is concentrated in one region and one product line, and recommends what to check next. A data scientist might separately build a model that predicts which customers are about to churn. A BI analyst maintains the live dashboard that surfaced the flat-revenue number in the first place. An analytics engineer is who built and maintains the pipeline that gets raw order data into a queryable table every night. Same company, four different, overlapping jobs.

How the adjacent roles differ

vs. Data Scientist, data scientists lean more on statistics, experimentation, and often machine learning to answer harder, more open-ended questions. Data analysts answer more immediate business questions with existing data and simpler methods. The line is blurry and many analysts grow into data science work.

vs. BI (Business Intelligence) Analyst, a BI analyst mostly builds and maintains recurring dashboards and reports. A data analyst does that too, but also does one-off, open-ended investigations that don't have a dashboard yet.

vs. Analytics Engineer, analytics engineers build and maintain the data pipelines and models that get raw data into a clean, queryable state. Analysts consume what analytics engineers build. Some companies don't distinguish the roles at all.

Your journey through this course

What you need before starting

Nothing. Track A starts from a completely blank spreadsheet. If you can use a computer and read a table, you can start Module 1.

You do NOT need prior coding, statistics, Excel, or database experience. This course teaches all of it, in order, starting from wherever your placement result says.

Core skills taught in this course

Spreadsheet fundamentals, Python for data, pandas and NumPy, real-world data cleaning, statistics you can defend in a meeting, chart selection and visualization, SQL, dashboard building, and a full capstone analysis you can put on a portfolio.

Skills to develop after the core course

Machine learning, advanced statistics (regression modeling, Bayesian methods), a dedicated BI tool (Tableau, Power BI) beyond the tool-agnostic dashboard skill taught here, and advanced SQL (window-function depth, query optimization). Genuinely useful next-stage skills, not prerequisites for starting here.
