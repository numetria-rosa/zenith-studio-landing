Integrated Cross-Tool Challenges

The same business question, answered in two different tools, the specific skill of recognizing that a SUMIF, a GROUP BY, a pandas groupby, a DAX Measure, and a Tableau shelf configuration are frequently the exact same idea wearing a different tool's syntax.

Honest scope note, please read: this is a decision-based practice simulation testing cross-tool translation judgment, not simultaneous live execution across three engines at once. The individual practice libraries (Excel, SQL, Python, Automation) already give you genuine, real-execution practice in each tool on its own, this library instead drills the judgment call of recognizing the SAME underlying technique across different tools' vocabularies, and knowing which tool a given step of a workflow actually belongs in. Every scenario is re-randomized on every attempt, and a task only counts as passed after 3 consecutive correct answers on 3 independently redrawn scenarios.
