Portfolio · Deployment

Put your portfolio on the real internet

A finished portfolio sitting only on your laptop doesn't get you a job. This is the exact path to a real, live URL you can put on a resume: free hosting on Vercel, and an optional custom domain if you want one.

↓ Download the portfolio template Back to My Portfolio
Honest scope: this page covers the deployment workflow itself, GitHub, Vercel, and DNS. It doesn't teach Git from scratch, if you've never used Git before, GitHub's own Hello World guide takes about 10 minutes and covers everything you need first.
1

Get your template onto GitHub

Vercel deploys directly from a GitHub repository, so that's the first stop, not optional.

  1. 1Unzip the templateyou downloaded above into its own folder, then edit index.html, replace every "EDIT ME" comment with your real name, links, and project write-ups.
  2. 2Create a new repository on GitHub(github.com → New repository). Name it something like my-portfolio. Leave it empty, no README, no .gitignore.
  3. 3Push your folder to itfrom a terminal inside the folder:
    git init
    git add .
    git commit -m "portfolio"
    git branch -M main
    git remote add origin https://github.com/yourusername/my-portfolio.git
    git push -u origin main
2

Deploy it on Vercel

Vercel's free tier is enough for a static portfolio site, no credit card required for this.

  1. 1Sign up at vercel.comusing your GitHub account, this lets Vercel see your repositories directly.
  2. 2Click "Add New" → "Project", then select the my-portfolio repository you just pushed.
  3. 3Leave every setting at its default(this is a plain static site, no framework, no build command needed) and click Deploy.
  4. 4You now have a live URLlike my-portfolio.vercel.app. Every future git push to main automatically redeploys it, no manual re-upload ever again.
3

Optional: buy and connect a real domain

A .vercel.app URL is genuinely fine to put on a resume. A custom domain (like yourname.com) is a nice-to-have, not a requirement, and it costs real money every year.

  1. 1Buy a domainfrom any registrar, Namecheap, Cloudflare Registrar, or directly inside Vercel's own dashboard under "Domains". Search your name or a variation of it.
  2. 2In your Vercel project, go to Settings → Domainsand add the domain you bought.
  3. 3Point the domain at Vercel. If you bought it directly through Vercel this is automatic. If you bought it elsewhere, Vercel shows you exactly which DNS records to add (usually one A record and one CNAME), you add those in your registrar's DNS settings.
  4. 4Wait for DNS to propagate, usually minutes, occasionally up to 24 hours, then your domain serves the same site as your .vercel.app URL, automatically over HTTPS.
