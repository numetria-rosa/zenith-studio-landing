1.1

What a dataset actually is

A dataset is a table. Each row is one observation (one order, one employee, one survey response). Each column is one variable about that observation (the date, the amount, the region). Every real analysis technique in this course, spreadsheets, pandas, SQL, is a different way of asking questions of that same row/column structure.

Definition: Tidy data

A dataset where every column is a single variable, every row is a single observation, and every cell is a single value. Not two dates crammed into one cell. Not a column that's sometimes text and sometimes a number. Tidy data is what makes a formula, a pandas function, or a SQL query behave predictably instead of silently doing the wrong thing.

Most real data you'll be handed is not tidy. Module 4 is dedicated entirely to fixing that. This module just needs you to recognize it.

1.2

The five formulas that cover most real work

SUM & AVERAGE

=SUM(B2:B50) adds a range. =AVERAGE(B2:B50) means it. These are almost always your first move on a new dataset, just to get a feel for the scale of the numbers.

COUNTIF

=COUNTIF(C2:C50,"Returned") counts how many cells in a range match a condition. The workhorse for "how many of X happened."

IF

=IF(B2>1000,"High","Low") branches on a condition. Nest a few of these and you have a basic categorization system without touching code.

XLOOKUP (and VLOOKUP)

=XLOOKUP(A2,Sheet2!A:A,Sheet2!B:B) finds a value in one table using a key from another. This is a spreadsheet doing a JOIN, the exact same operation Module 6's SQL JOIN and Module 3's pandas merge() both do, just with different syntax.

Sorting, filtering, and building a summary table

Sorting reorders rows without changing them. Filtering hides rows that don't match a condition, also without changing them. Both are non-destructive, which is exactly why they're the first thing to reach for before writing any formula: they let you SEE the answer before you have to compute it.

Sorting and filtering never change the underlying data. Why does that matter more than it sounds like it should?

Check your answer
Because it means you can explore a dataset freely, sort ten different ways, filter to five different subsets, without any risk of corrupting the source data. A formula that writes a new value can make a mistake permanent; sorting and filtering are always safe to undo, which is exactly why they're the right first move on unfamiliar data.
