# Northline Landing — Desktop Lab A starter

Fictional clinic page for **AI-Assisted Software Engineering**.

## Lab A

1. Open this folder in Cursor (or VS Code + Copilot).
2. Change hours to **Tue–Sat 9:00–17:00**.
3. Add a button whose visible text is **Book**.
4. Commit and push to a GitHub repo you own.
5. Paste the `https://github.com/.../commit/...` URL on the course Desktop Labs page.

This folder is not a live deploy and does not run a coding agent in the browser.
