Desktop Labs

Unlike Data Science (Tableau or Power BI), this course needs both Cursor evidence and a GitHub repo you own. In-browser labs are labeled simulations. They do not satisfy this page.

This page cannot open Cursor or inspect your repo for you. Lab A is self-reported. Lab B checks URL shape always, and asks GitHub's public API when the browser can reach it. A 404 fails. Rate-limits and CORS do not fail the lab — they are labeled “format valid, contents not confirmed.”

A

Lab A — Cursor

Install Cursor (VS Code + Copilot is accepted if you confirm it). Open the starter in starters/northline-landing/. Change the clinic hours to Tue–Sat 9:00–17:00 and add a button whose visible text is Book. Commit and push if you can.

What counts as success

Do: a real editor session, then answer every field including what AI got wrong, whether you would ship, and what you would monitor. Submit: the form, not a screenshot of chat. This page cannot see Cursor. Lab B can ask GitHub’s API whether the repo exists.

B

Lab B — GitHub

A public repo you own with a README, at least three commits, and either one pull request or a documented feature branch. One repo may satisfy both labs if the commit URL is valid and the repo checks pass.
