03

The box, the row, and the grid

Colour is the easy part of CSS. Layout is the part with a right answer. Every element is a box: content, then padding (inside, background reaches it), then border, then margin (outside, background does not).

Before — default box
.card {
  width: 300px;
  padding: 20px;
  border: 2px solid;
}
/* Rendered: 344px */
then
After — border-box
*, *::before, *::after {
  box-sizing: border-box;
}
/* width: 300px means 300px */

Flexbox is one axis. You set it on the parent:

.nav {
  display: flex;
  gap: 20px;
  align-items: center;
  justify-content: space-between;
}
/* The phone move: flex-wrap: wrap  or  flex-direction: column */

Grid is two axes. One line that reflows without a media query:

.services {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 20px;
}

Read that in English: fit as many columns as you can, each at least 240px, sharing leftover space. Wide screen: several columns. Phone: one. You described a constraint, not a device list.

Hierarchy, contrast, and the outline you must not delete
  • Size and weight — two or three sizes, not seven.
  • Space — related things sit close; unrelated things get a gap.
  • Contrast — body text needs a real ratio against its background. Light grey on white fails.
  • Never outline: none — that ring is how a keyboard user knows where they are. Restyle it; do not delete it.

The three things that actually fix a phone

  1. Viewport meta tag. Without it, a phone pretends to be 980px and shrinks everything. 
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
  2. Stop using fixed widths for layout. max-width is a ceiling. width: 420px is a promise a 375px screen cannot keep. 
    main { max-width: 68ch; margin: 0 auto; padding: 0 20px; }

    ch is the width of a “0” in the current font — roughly a readable line length, not a device size. Specificity is how CSS decides which rule wins when two rules target the same element: more specific selectors beat less specific ones; !important is the agent’s way of skipping that conversation.

  3. Then one media query at the width where your layout breaks — found by shrinking the window, not from a device list. 
    @media (max-width: 640px) {
  .layout { flex-direction: column; }
}
Where the agent trips. Five breakpoints at "standard" device widths, none of which match your content. And !important when a rule loses, instead of finding out why. Both work today. Both make the next change harder.
Engineer's tip. AI can make a page look responsive at one breakpoint while quietly breaking another. Test the behaviour — shrink the window, tap the button — not just the code.

Layout spec

1. Border-box sizing applied to everything.
2. .layout puts .main and .side in a row with at least 16px between them.
3. .page is centred with a max-width no greater than 900px.
4. .services is a grid whose columns are at least 200px and reflow on their own.
5. At 640px and below, .layout stacks into a column.
6. Focus outlines are not removed anywhere.
