AI as a step, not a brain

The model is a flaky function that returns text. Your workflow needs data. If you cannot name the JSON you will accept, you are not ready to add an AI node.

You will be able to
  • Demand a schema from an AI step
  • Reject conversational prose even when it "sounds right"
  • Keep billing, refunds, and emails out of the model's hands
1

Prose is not a ticket label

You asked for {"priority":"high","topic":"billing","needs_human":true}. The model said "Sure! This looks urgent." That is not a bug in the API. That is the default. A repair pass can strip a markdown fence. It cannot invent a topic you can route on.

Rule: AI labels, extracts, and drafts. Deterministic code writes to the CRM, charges cards, and sends mail.
