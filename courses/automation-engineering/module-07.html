Agents that can't run away

Giving an agent a tool is giving it a way to spend money, email a list, or delete a record. If refund.execute is on the tool list and there is no human node, you did not build an agent. You built a liability.

You will be able to
  • Split "draft" tools from "execute" tools
  • Require an approval node before a destructive action
  • Explain a runaway loop in one sentence

The tool list is the permission list

refund.draft is a sentence. refund.execute moves money. Clients will ask for "a refund agent." Your job is to hear "draft plus a button a human presses."

Prompt injection is not theoretical. If the ticket text can talk the agent into calling execute, the only real control is: the execute tool is not attached, or it is behind approval.
