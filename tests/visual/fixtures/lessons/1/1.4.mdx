Treat model output the way you would treat a form a stranger submitted: it is untrusted input. It might be valid JSON with the wrong fields, the right fields with the wrong types, or a polite sentence with no JSON at all.

Better prompting makes that rarer. Validation decides what happens when it still occurs, and it will.

## Validate at the boundary

Define the shape once, as a Pydantic model, and let it reject anything that doesn’t match. Every downstream function then receives a `Ticket`, never a raw string.

```python filename="ticket.py"
from typing import Literal
from pydantic import BaseModel, ValidationError

class Ticket(BaseModel):
    intent: Literal["refund", "billing", "bug", "other"]
    order_id: int | None
    urgency: Literal["low", "medium", "high"]

try:
    ticket = Ticket.model_validate_json(raw)
except ValidationError as err:
    print(err.errors()[0]["loc"], err.errors()[0]["msg"])
```
